System Overview

Hybrid HRIS is a specialized Human Resource Information System designed for organizations that require both flexibility and rigorous financial-grade integrity. Built on a modular NestJS and Next.js foundation, the system ensures that every employee action—from filing a leave to claiming an expense—is tracked via immutable ledgers.

Immutable Audit Trail

Balances for leaves and budgets are derived from append-only ledgers, making the system tamper-proof.

Modular Architecture

Clean separation between business domains allows for rapid scaling and easy maintenance.

The Leave module handles time-off requests with real-time balance verification. When a user submits a request, the system checks their current ledger balance before allowing the submission.

Hardened Security

Database-First Authorization

Unlike traditional systems that trust JWT roles, Hybrid HRIS re-verifies user roles and leadership assignments directly from the database for every critical action. This prevents "Stale Token" vulnerabilities and ensures immediate revocation of access.

Temporal Integrity

Using Postgres `EXCLUDE` constraints with the `btree_gist` extension, the system ensures that an employee can never have overlapping leave policies or shift assignments, effectively preventing data corruption at the database level.
